# 熟語参照の語義別補完（0041）

既存の732項目を確認し、語義の対応が明確な69項目・70語義に76件の参照を補完する。全ての類義語候補を網羅したという意味ではない。

参照先は最新のCrossover全単語データの語義・構文を照合。既存の構成語・関連語への参照は保持する。新しい見出し語は追加しない。参照は完全な同義・無条件の置換可能性を表さない。

look intoの「中をのぞく」、look overの「見渡す」、go intoの「入る」、go throughの「経験する」には調査・検査の参照を追加しない。複数の意味が一つの語義に混在し、対応が曖昧な候補は今回の追加対象にしない。

call off → cancelなど、現在の単語帳に参照先の見出し語がない候補は未追加。stand by → desertのような既存の対比的な関連先も削除せず、supportを補う。
