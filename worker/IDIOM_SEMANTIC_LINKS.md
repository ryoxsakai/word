# 熟語の参照は意味の近い単語に限定（0042）

ユーザーの方針変更により、構成語への参照と、単なる話題・対比のための参照を解除する。0041以前の「既存参照を全て残す」方針に優先する。

look into → investigate、look up to → respect / admire、let down → disappoint。適切な参照先がない語義は refs=[] とし、本のアイコンも表示しない。熟語・語義・分類は保持する。

参照646件を解除し、意味に対応する202件を保持。参照あり180項目、参照なし552項目。

sourceの値だけでは判断しない。0040・0041で確認した語義別参照と、旧データのsubmit・care・compensateなどの適切な参照を残す。bring forward → postpone、stand by → desert、in favor of → opposedの対比参照は解除する。

0042のバックアップに解除前の参照を保存する。対象の語義・表記・参照元がスナップショットから変わっていた場合は解除しない。新しい語義・参照にも影響しない。

リンクのない熟語は「全表示」で引き続き表示する。既存の英検フィルターは参照語のタグに基づくため、参照のない熟語を特定級には割り当てない。
