# 熟語の補助欄・型の整理（0048 / 0049）

既存のD1のidiomsテーブルに同義語（synonyms）、対義語（antonyms）、メモ（notes）、非表示（hidden）、統合前の別名（aliases）を追加。別DBは作らない。

## 内容

| 項目 | 結果 |
|---|---|
| 実質1語の項目 | 50項目を非表示。削除せず編集画面から復帰可能 |
| 型の統合 | 26項目分を統合。1,793項目を保存し、1,743項目を表示 |
| 表示構成 | 9 Chapters・22 Groups・109 Sections。非表示だけのSectionはナビにも表示しない |
| メモ | 79項目。用法、型の区別、例示を意味欄から分離 |
| 過去分詞 | 熟語の見出し・意味・メモ・SectionタイトルをVppに統一 |
| 複数語義 | ／・；で区切られた独立語義を分離。同じ意味は参照を保持して集約 |
| 語義番号 | ①②③の実体文字。先頭のみ強調し、検索時も元の番号を維持 |

旧Section 2のwill do / sell well、旧Section 7のreply to Oなどの複数語表現は残す。be Cやanswer Oだけでなく同じ基準のlook C、watch O、物 fit 人なども非表示にする。SVOC・SVOO・不定詞等の複雑な型は保持する。

have O V / Ving / Vpp、get O to V / Vpp、知覚動詞のV / Ving / Vpp、take / catch / hold O by the arm、with O Cの各補語を統合。型ごとの違いはメモに記録する。異なる意味のsee through O / see O through等は統合しない。

## 記法とリンク

単語と同じrenderMarkup / renderWordListMarkup / createAutoCrossRefRendererを使用する。

- `##respect##` / `##look up to O##`：単語・熟語の完全一致参照。
- `##idiom:look up to O|look up to##`：熟語を明示し表示名を変更。
- `##word:respect##`：単語を明示。
- 同義語・対義語の裸のカンマ区切りも自動リンク。メモも同じ自動参照・太字・強調・IPA記法。
- 同名の単語を既定で優先。複数の熟語へ解決される曖昧な別名は自動リンクしない。
- 統合前の表記とIDはaliasesに保存し、古い名前・URLも統合先へ解決。V-ed表記も別名として保持。
- 非表示項目には通常のリンクを作らない。URLで直接来た場合は非表示の旨を表示。
- 単語・熟語間の参照はタブを切り替えて移動。検索・英検フィルタで対象が隠れる場合は解除。

## 編集

`/setting/idioms.html`（単語編集画面の「熟語」リンク）で単語帳・Section・文字検索・非表示を切り替え、見出し・語義の順序・同義語・対義語・メモを編集する。新規項目も作成可能。記法のプレビューは単語・熟語にリンクする。

既存のOAuth付き編集APIを使用。PUTで新しい文字列フィールドを省略した古いクライアントは既存値を保持する。空文字で明示的にクリアできる。hiddenはboolean。語義IDを渡すとIDと既存参照のsourceを保持し、他項目の語義IDの流用は拒否する。並べ替え指定がなければ既存の掲載順を保持する。

## 保護・確認

0049は元の項目・意味・新フィールドが想定と一致することを確認し、不一致なら停止。変更前の語義・参照・分類をrevision 0049に退避。単語データは変更しない。

SQLiteで全出力をfixtureと比較し、全参照の保持、メモへの移動、型統合、非表示、Vpp、編集の再読込、入力エラー時の非変更を検証。共有記法のHTML安全性、リンク先の種別・別名、非表示Section、絞り込み時の番号もテストする。既存の公開／OAuth編集ルートの制限は維持する。
