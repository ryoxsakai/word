# 閲覧型編集ページ 仕様

`/setting/` を置き換える新しい編集ページ。閲覧ページ（`public/viewer/`）とほぼ同じ見た目のまま、その場で編集する。単語帳と熟語の両方が対象。熟語は閲覧ページと同じくタブで切り替える。

## 1. 置き換えと残す画面

- 既存の「通常編集（一覧＋モーダル）」「カード編集」は廃止し、新画面に置き換える。
- 新画面に組み込む既存機能：辞書から下書き、発音記号の取得。
- 新画面に組み込まず別ページとして残す機能：音声生成、イラスト管理、マスター一覧（AWL・Oxford絞込）、単語帳の作成・設定・単語帳への追加、閲覧ページの再生成（`feat/viewer-regeneration`）。新画面のメニューからリンクする。
- 対象の単語帳はcrossover（閲覧ページと同じ）。

## 2. 端末と基本操作

スマホ中心で設計し、PCにも対応する。

| 操作 | スマホ | PC |
|---|---|---|
| 単語・熟語を選択（編集部品を表示） | タップ | クリック |
| テキストを編集 | ダブルタップ | ダブルクリック |
| 確定 | 欄の外をタップ／キーボードの完了 | Enter（メモなど複数行の欄はCtrl+Enter）／欄の外をクリック |
| 取消 | 「×」ボタン | Esc |
| 次の欄へ | ― | Tab |
| 並べ替え | 番号を長押ししてドラッグ | 番号をドラッグ |

- 普段は閲覧ページと同じ見た目。選択した単語・熟語にだけ＋−ボタン、ドラッグハンドル、…メニューを表示する。
- 編集ページでは参照リンクをタップしてもジャンプしない（選択操作を優先する）。

## 3. テキスト編集

- ダブルタップした箇所だけが、同じ位置・同じ文字サイズの入力欄に変わる。
- 入力欄には記法の元テキスト（`**太字**`、参照記法など）を表示する。確定すると描画済みの表示に戻る。
- 編集できる箇所：見出し、発音記号、意味、フレーズとその訳、派生語（語・意味）、不規則・類義語・対義語・関連語・語源・メモ。熟語では熟語本体、別形、意味、同義語・対義語・メモ。
- 文章の欄は内容に応じて高さを自動調整する。

## 4. バッジとタイル

選択中の単語でバッジ部分をタップすると、タイルの一覧が出て、タップで付け外しできる。

| 種類 | 位置 | タイルの内容 |
|---|---|---|
| 注意バッジ | 見出しの右 | 能格・スペル・発音・アクセント・多義・活用・語法 |
| 品詞バッジ | 意味の行の先頭 | 名・動・形・副など（既存の品詞の一覧） |
| 欄のバッジ | 単語の下部 | 派生語・不規則・類義語・対義語・関連語・語源・メモ。付けるとその欄が空で追加され、すぐ入力欄が開く。外すとその欄の内容を削除する |
| CEFR・AWL | 見出しの右 | 暫定CEFR（A1〜C2・なし）、AWL（Sublist 1〜10・なし）。Oxfordの公式値がある語では暫定CEFRは表示に影響しない旨を出す |

## 5. ＋／−ボタン

選択中の単語・熟語にだけ表示する。

| 対象 | ＋ | − |
|---|---|---|
| 意味 | 同じ品詞の行に②③…を追加。行の最後に「＋品詞」で新しい品詞の行を追加 | その意味を削除 |
| フレーズ | フレーズの末尾に□を追加し、すぐ入力欄を開く | その行を削除 |
| 派生語 | 派生語の欄に1件追加 | その派生語を削除 |
| 単語・熟語 | 選択中の単語の下に＋を出し、その位置に新しい単語を挿入して見出しの入力欄を開く | …メニューの「削除」（確認あり） |

- 例文（◆）は廃止する。既存の例文はデータ移行ですべてフレーズ（□）に変換する。訳と穴埋めの答えは保持する。閲覧ページの表示も□に変わる。
- 新しい単語は既存APIで自動採番する。挿入位置は並べ替えとして保存する。
- 新しい単語の…メニューに「辞書から下書き」「発音記号を取得」を置く。

## 6. 詳細パネル

閲覧ページに表示されない項目は、選択中の単語の…メニュー「詳細」で開くパネルで編集する。

- 英検タグ・カスタムタグ、穴埋めの答え、品詞別の発音、派生元、見出しの意味（①にする意味）など。
- 熟語では「非表示」もここで切り替える。非表示の熟語は編集ページでは薄く表示する。

## 7. 単語の移動

- 同じSection内は番号を長押ししてドラッグする。Labelをまたぐ移動もドラッグで行う。画面の端では自動でスクロールする。
- 別のSectionへは…メニューの「移動」で移動先のSection・Labelを選ぶ。複数の単語をまとめて選んで移動することもできる。

## 8. Chapter・Section・Labelの設定

見出しの直接編集と目次での一括操作の両方を用意する。

- 見出しの直接編集：Chapter扉・Section帯・Label見出しをダブルタップして名前・説明を編集する。境目の＋で新規作成、…メニューで削除・移動。
- 目次：閲覧ページの目次メニューを拡張し、作成・名前変更・並べ替え（ドラッグ）・削除を行う。
- 削除は確認ダイアログを出す。中に単語があるSection・Labelの扱いは既存APIの仕様に従う。

## 9. 保存

当初の「確定ごとに自動保存」から、単語・熟語とも「下書き → 保存」に変更した。保存の流れ・進み具合・エラー時の操作・言葉は、リポジトリ直下の `DESIGN.md`（4章・5章）を正とする。

- 内容の変更は下書きに入り、項目の「保存」でDBに書き込む。「変更を取り消す」で保存済みの内容に戻す。
- 項目をタップした時点でDBの最新を読み、下書きの起点にする（公開の遅れによる誤った衝突を防ぐ）。
- ほかの画面で同じ項目が変わっていたら保存を止め、「最新を読み込む」か「上書きして保存」を選んでもらう。
- 並べ替え・移動・Chapter・Section・Labelの変更はすぐ保存する。直前の操作は「元に戻す」付きのトーストで取り消せる。削除は確認ダイアログを出す。
- 閲覧ページへの反映は保存とは別に、上部の表示とトーストで知らせる。

## 10. 読み込みと表示

- 閲覧ページと同じ描画処理（`word-entry.js`・`idiom-entry.js`）を使い、見た目を揃える。編集用の部品は上に重ねて表示する。
- 読み込みはChapter・Section単位とし、閲覧ページと同じ順に表示する。
- 保存した単語はその場で描画し直し、スクロール位置を保つ。
- ログインは既存の認証（`auth.js`）を使う。

## 11. 実装状況（第1版）

| 項目 | 状況 |
|---|---|
| 画面 | `public/setting/index.html`（新しい編集ページ）。処理は `public/setting/edit/`。旧画面は `public/setting/classic.html` に移し、熟語の旧画面 `idioms.html` とともに残す |
| 見た目 | 閲覧ページの `viewer/style.css` と描画処理（`word-entry.js`・`idiom-entry.js`）をそのまま使う。描画処理は `edit` を渡したときだけ編集用の属性を付けるので、閲覧ページの出力は変わらない |
| 単語 | 第1〜10章の内容をすべて実装 |
| 熟語 | 熟語・別形・意味・同義語・対義語・メモの編集、意味の追加・削除、熟語の追加、並べ替え（ドラッグ）、Sectionの移動、非表示、Section名の変更、Sectionの並べ替え |
| 例文の変換 | `worker/migrations/0061_examples_to_phrases.sql`（承認済み）。デプロイ時に既存の例文をすべてフレーズに変える。REST・MCPとも、以後は種類を問わずフレーズとして保存する（MCPの `type: "example"` は互換のため受け付ける）。閲覧ページへは、デプロイ後の最初の編集か `/mcp-viewer-publish` で反映される |
| テスト | `npm --prefix worker run test:viewer-edit`（実際のブラウザで操作を確認する） |

### 仕様との違い（既存APIの範囲による）

| 項目 | 内容 |
|---|---|
| 熟語の削除 | 熟語を削除するAPIがないため、…メニューの「非表示」で代える。非表示の熟語は編集ページでは薄く表示し、番号は付けない |
| 熟語のChapter・Section・Label | 作成・削除と、Labelの変更はできない（Section名の変更と、同じChapter内での並べ替えだけ） |
| 熟語のLabel | 表示のみ。ドラッグで別のLabelの位置へ移すと、そのLabelに所属を変える |
| 単語のGroup | 表示のみ（編集は旧画面またはMCP） |
| 単語のLabelの並べ替え | APIがないため未対応（作成・名前変更・削除は可能） |
| 単語の削除 | 単語帳から除外する（単語マスターのデータは残る）。番号は表示順で振り直す |

## 12. 閲覧ページと同じ操作性・読み込み（第2版）

| 項目 | 内容 |
|---|---|
| 上部 | 単語・熟語・索引のタブ。ハンバーガーの目次はタブに応じて切り替わる（単語タブではつまみで並べ替え） |
| 下部 | Sectionナビ（熟語タブでは熟語のSection、索引タブでは頭文字）。画面の中ほどにあるSectionを強調する |
| 移動 | 閲覧ページと同じ手順。移動中は先読みを止め、移動先と直前の画面1枚分ほどのSectionだけを読み込み、実寸で確定してから位置を合わせる。途中のSectionやその画像は読み込まない |
| 画像 | 閲覧ページと同じく、画面に近づいたイラストから読み込む |
| データ | Sectionの表示データは閲覧ページと同じ公開APIと端末キャッシュ（IndexedDB）で読む。保存直後の単語・熟語は、閲覧ページへの反映まで手元の保存結果を表示する |
| 検索 | 歯車メニューの検索で、見出し語・熟語・本文の一致を一覧し、タップでその場所へ移動して選択する |
| 索引 | 閲覧ページと同じ並び。タップでその単語・熟語へ移動して選択する |
| 本文の自動リンク | 閲覧ページがChapterごとに候補を絞るのと同じく、本文に出てくる語句だけで照合する（`createScopedCrossRefRenderer`）。日本語や「～」を含む語句も同じく絞る。例文をフレーズに変えたことで候補が数千に増え、単語帳全体で照合すると読み込み後に1分近く固まっていたため。結果は全体で照合した場合と同じ |
