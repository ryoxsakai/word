# 閲覧型編集ページ 仕様（案）

`/setting/` を置き換える新しい編集ページ。閲覧ページ（`public/viewer/`）とほぼ同じ見た目のまま、その場で編集する。単語帳と熟語の両方が対象。熟語は閲覧ページと同じくタブで切り替える。

## 1. 置き換えと残す画面

- 既存の「通常編集（一覧＋モーダル）」「カード編集」は廃止し、新画面に置き換える。
- 新画面に組み込む既存機能：辞書から下書き、発音記号の取得。
- 新画面に組み込まず別ページとして残す機能：音声生成、イラスト管理、マスター一覧（AWL・Oxford絞込）、単語帳の作成・設定・単語帳への追加、閲覧ページの再生成（`feat/viewer-regeneration`）。新画面のメニューからリンクする。
- 対象の単語帳はcrossover（閲覧ページと同じ）。

## 2. 端末と基本操作

スマホ中心で設計し、PCにも対応する。

| 操作 | スマホ | PC |
|---|---|---|
| 単語・熟語を選択（編集部品を表示） | タップ | クリック |
| テキストを編集 | ダブルタップ | ダブルクリック |
| 確定 | 欄の外をタップ／キーボードの完了 | Enter（メモなど複数行の欄はCtrl+Enter）／欄の外をクリック |
| 取消 | 「×」ボタン | Esc |
| 次の欄へ | ― | Tab |
| 並べ替え | 番号を長押ししてドラッグ | 番号をドラッグ |

- 普段は閲覧ページと同じ見た目。選択した単語・熟語にだけ＋−ボタン、ドラッグハンドル、…メニューを表示する。
- 編集ページでは参照リンクをタップしてもジャンプしない（選択操作を優先する）。

## 3. テキスト編集

- ダブルタップした箇所だけが、同じ位置・同じ文字サイズの入力欄に変わる。
- 入力欄には記法の元テキスト（`**太字**`、参照記法など）を表示する。確定すると描画済みの表示に戻る。
- 編集できる箇所：見出し、発音記号、意味、フレーズとその訳、派生語（語・意味）、不規則・類義語・対義語・関連語・語源・メモ。熟語では熟語本体、別形、意味、同義語・対義語・メモ。
- 文章の欄は内容に応じて高さを自動調整する。

## 4. バッジとタイル

選択中の単語でバッジ部分をタップすると、タイルの一覧が出て、タップで付け外しできる。

| 種類 | 位置 | タイルの内容 |
|---|---|---|
| 注意バッジ | 見出しの右 | 能格・スペル・発音・アクセント・多義・活用・語法 |
| 品詞バッジ | 意味の行の先頭 | 名・動・形・副など（既存の品詞の一覧） |
| 欄のバッジ | 単語の下部 | 派生語・不規則・類義語・対義語・関連語・語源・メモ。付けるとその欄が空で追加され、すぐ入力欄が開く。外すとその欄の内容を削除する |
| CEFR・AWL | 見出しの右 | 暫定CEFR（A1〜C2・なし）、AWL（Sublist 1〜10・なし）。Oxfordの公式値がある語では暫定CEFRは表示に影響しない旨を出す |

## 5. ＋／−ボタン

選択中の単語・熟語にだけ表示する。

| 対象 | ＋ | − |
|---|---|---|
| 意味 | 同じ品詞の行に②③…を追加。行の最後に「＋品詞」で新しい品詞の行を追加 | その意味を削除 |
| フレーズ | フレーズの末尾に□を追加し、すぐ入力欄を開く | その行を削除 |
| 派生語 | 派生語の欄に1件追加 | その派生語を削除 |
| 単語・熟語 | 選択中の単語の下に＋を出し、その位置に新しい単語を挿入して見出しの入力欄を開く | …メニューの「削除」（確認あり） |

- 例文（◆）は廃止する。既存の例文はデータ移行ですべてフレーズ（□）に変換する。訳と穴埋めの答えは保持する。閲覧ページの表示も□に変わる。
- 新しい単語は既存APIで自動採番する。挿入位置は並べ替えとして保存する。
- 新しい単語の…メニューに「辞書から下書き」「発音記号を取得」を置く。

## 6. 詳細パネル

閲覧ページに表示されない項目は、選択中の単語の…メニュー「詳細」で開くパネルで編集する。

- 英検タグ・カスタムタグ、穴埋めの答え、品詞別の発音、派生元、見出しの意味（①にする意味）など。
- 熟語では「非表示」もここで切り替える。非表示の熟語は編集ページでは薄く表示する。

## 7. 単語の移動

- 同じSection内は番号を長押ししてドラッグする。Labelをまたぐ移動もドラッグで行う。画面の端では自動でスクロールする。
- 別のSectionへは…メニューの「移動」で移動先のSection・Labelを選ぶ。複数の単語をまとめて選んで移動することもできる。

## 8. Chapter・Section・Labelの設定

見出しの直接編集と目次での一括操作の両方を用意する。

- 見出しの直接編集：Chapter扉・Section帯・Label見出しをダブルタップして名前・説明を編集する。境目の＋で新規作成、…メニューで削除・移動。
- 目次：閲覧ページの目次メニューを拡張し、作成・名前変更・並べ替え（ドラッグ）・削除を行う。
- 削除は確認ダイアログを出す。中に単語があるSection・Labelの扱いは既存APIの仕様に従う。

## 9. 保存

- 項目を確定するたびに、その単語・熟語を自動保存する（入力欄を閉じる、バッジの付け外し、＋−、ドラッグ、移動）。
- 保存直前に最新データを読み直し、変更した欄だけをマージする。同じ欄が別の内容に更新されていたら保存を止めて知らせる（今のカード編集と同じ）。
- 保存に失敗したら理由を表示し、入力内容を残す。自動では再送しない。
- 直前の操作は「元に戻す」付きのトーストで取り消せる。単語・Chapter・Section・Labelの削除だけは確認ダイアログを出す。
- 閲覧ページへの反映（自動公開）の状況はトーストで知らせる（公開中・公開済み・失敗）。

## 10. 読み込みと表示

- 閲覧ページと同じ描画処理（`word-entry.js`・`idiom-entry.js`）を使い、見た目を揃える。編集用の部品は上に重ねて表示する。
- 読み込みはChapter・Section単位とし、閲覧ページと同じ順に表示する。
- 保存した単語はその場で描画し直し、スクロール位置を保つ。
- ログインは既存の認証（`auth.js`）を使う。
